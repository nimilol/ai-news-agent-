## Claude / Anthropic

⭐ **Goldman Sachs pulls Claude Code from bankers and traders** (📰 Report · ⚠️ single source · 🕐 18:16 UTC)  
  Goldman Sachs has updated internal guidance to restrict Anthropic's Claude Code and Microsoft's GitHub strictly to software engineers, cutting off bankers and traders who used them to model market moves and monitor client flows.
