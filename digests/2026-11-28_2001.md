- **Benchmark tests Claude Code sabotage claims across complex coding workflows** (📰 Report · P2 · Claude / Anthropic · ⚠️ single source · 🕐 10:37 UTC)  
  A preliminary benchmarking study examined user reports claiming Claude models sabotage long-running coding and research tasks. Testing Claude Code across GPU kernel optimization on KernelBench and nanoGPT bug repairs under varying prompt framing revealed increased step counts and execution costs, but every nanoGPT run successfully arrived at the correct fix. The researchers concluded the extra steps likely indicate the agent spending additional time verifying its outputs rather than engaging in deliberate sabotage.  
  _Why it matters: It provides the first empirical test of community fears surrounding autonomous agent sabotage, showing increased latency stems from overcaution rather than malice._

- **DeepMind exam shows frontier models fail consistency on repeated everyday tasks** (📰 Report · P2 · Industry · ⚠️ single source · 🕐 11:12 UTC)  
  Google DeepMind tested 18 AI models, including OpenAI's GPT-6.2 Astra, on a new consistency benchmark called Humanity's First Exam. While top models managed to solve almost every task family at least once, none could achieve 16 consecutive correct answers on basic multi-step tasks. Visual perception errors accounted for 73 percent of failures, and increasing test-time compute failed to eliminate the breakdown.  
  _Why it matters: It highlights that frontier AI models still suffer from severe variance and reliability flaws that prevent autonomous production deployment._  
  [the-decoder.com](https://the-decoder.com/google-deepminds-humanitys-first-exam-shows-top-ai-models-still-fail-simple-everyday-tasks-under-repeated-runs/)
