## Claude / Anthropic

🔥 **Anthropic opens Claude Duet research preview, a proactive AI agent** (✅ Official · 13 sources · 🕐 19:14 UTC)  
  Anthropic announced a research preview of Claude Duet, a proactive personal‑agent app available to US Pro and Max subscribers. The app runs as a standalone web and mobile application, uses persistent virtual machines, sends daily briefs, monitors services such as Slack and Stripe, and performs multi‑step tasks in the background, asking for user approval before purchases or key external actions. The preview follows existing plan usage limits.  
  [support.claude.com](https://support.claude.com/en/articles/12138966-release-notes) · [testingcatalog.com](https://www.testingcatalog.com/claude-duet/) · [reddit.com](https://www.reddit.com/r/ClaudeAI/comments/1xbx2hk/anthropic_just_announced_claude_duet/)

⭐ **Anthropic adds CCU billing and US data residency surcharge on AWS** (✅ Official · 🕐 21:42 UTC)  
  Anthropic updated Claude API pricing for Claude Platform on AWS, converting billing to Claude Consumption Units (CCUs) billed hourly through AWS Marketplace at $0.01 per CCU. The update also institutes a 1.1x pricing multiplier for Claude 4.6 and subsequent models when customers require US-only inference residency via inference_geo: 'us'.  
  [platform.claude.com](https://platform.claude.com/docs/en/about-claude/pricing)

## GPT / OpenAI

⭐ **OpenAI's GPT‑5.6 Sol and Google's Gemini 4 Argon uncover critical PHP vulnerability** (✅ Official · 6 sources · 🕐 21 Oct)  
  OpenAI reported that its GPT‑5.6 Sol model discovered a widespread PHP vulnerability as part of the Patch the Planet initiative. Security firm Wiz independently identified the same flaw, and Google’s Gemini 4 Argon model was also cited in the discovery. The issue was covered by Gizmodo, TechCrunch and other outlets.  
  [openai.com](https://openai.com/index/empowering-cyber-defenders) · [reddit.com](https://www.reddit.com/r/OpenAI/comments/1xbv6g7/hitting_the_cybersecurity_wall_while_trying_to/) · [youtube.com](https://www.youtube.com/watch?v=ehcBwqyUGjo)

- **OpenAI API adds project-level controls for service tier access** (✅ Official · 🕐 21:42 UTC)  
  OpenAI updated its API platform settings to allow administrators to restrict service tier access on a per-project basis. Organization-level controls can now enforce tier restrictions globally across all workspace projects to manage costs and prevent misconfigurations.  
  [platform.openai.com](https://platform.openai.com/docs/changelog)
