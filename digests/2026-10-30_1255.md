## Claude / Anthropic

🔥 **Official Claude Code extension compromised to install SSH backdoor** (📰 Report · 4 sources · 🕐 05:52 UTC)  
  Cybersecurity researchers discovered that the official Anthropic Claude Code extension hosted on the Cursor Marketplace was compromised to install a persistent SSH backdoor and remote access trojan on developer machines. The trojanized extension targeted developer environments during an active compromise window before discovery. Security researchers from Phorion and DoublePulsar urged all affected users to inspect their environments for unauthorized SSH access and revoke exposed credentials.

## Across the industry
